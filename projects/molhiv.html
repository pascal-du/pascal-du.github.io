Combining Graph Representation Learning with Molecular Fingerprints

  • Main Contributor: GPT-5.6 Sol High
  • Proofread and edited: Pascal

Abstract

Molecular activity prediction can be achieved through a multitude of machine learning methods. This project studies representations and ensemble choices for the task of molecular HIV inhibitor prediction on the ogbg-molhiv dataset. Across five seeds, a random forest using concatenated molecular fingerprints achieves test ROC-AUC \(0.8385\pm0.0017\). Atom-feature masking and learned graph-fingerprint fusion improves validation performance more consistently than test performance. Exploring multiple GNN architectures, we identify GatedGCN as a candidate ensemble component achieving test ROC-AUC \(0.7925\). A validation-selected RF/GatedGCN blend reaches ROC-AUC \(0.8415\) and adding a small descriptor-SVM contribution yields a score of \(0.8416\).

Introduction

After completing my dissertation, I had a fair amount of colab credits leftover and decided I wanted to use the knowledge I acquired about GNNs and try working on a domain I knew nothing about. In my research I found the Stanford Open Graph Benchmark which compiles various domain specific graph datasets we can use for training classifiers. The dataset I decided to focus on was ogbg-molhiv.


The task is to create a model which can identify HIV protease inhibitors among a set of chemical compounds. Because molecular graphs and engineered fingerprints encode different aspects of chemical structure, intuitively we try to create a learning model incorporating different aspects by exploring varying splits and using optimal features. Practically, this is dependent on the learner, optimisation procedure, and the features embedded in each atomic struture. As such, we explore three questions in this regard:

  1. Whether feature masking or learned fingerprint fusion improves a fixed graph baseline.
  2. If alternative propagation operators offer useful predictive diversity.
  3. Can output-level ensembles improve upon strong fingerprint RFs.

This study contributes an imperical comparison of the implementations and configurations tested here. The underlying graph operators, fingerprints, and ensemble mechanisms are established techniques.


Methodology

Dataset

ogbg-molhiv is a binary molecular activity benchmark containing \(41,127\) graphs with scaffold partitions \(32,901\), \(4,113\), and \(4,113\) graphs for training, validation and testing respectively, each including \(1,232\), \(81\), and \(130\) positive labels. Molecule-derived features follow the row order of OGB's SMILES mapping; cached atom features are checked against graph node counts and offsets.


ROC-AUC is the primary metric and is computed over all molecules in a split, rather than averaged over minibatches. Neural models supply logits, forests supply positive-class probabilities, and the support-vector classifier supplies decision scores. ROC-AUC depends on score ordering and does not require these scores to be calibrated. Average precision (AP) is additionally reported for the descriptor-only classifiers. Neural checkpoints maximize validation ROC-AUC; ties retain the earlier checkpoint. Descriptor hyperparameters and ensemble weights are selected by validation ROC-AUC. Training and fitted preprocessing use the training partition only; selected models are not refitted on training plus validation data.


The neural representation comparison uses seeds \(0-4\), and the \(5,000\)-tree rich-fingerprint forest baseline uses seeds \(5-9\). The architecture comparison uses seed \(0\), and the attributed fusion experiment uses seeds \(0-2\). These seed sets differ, so comparisons between graph models and the forest baseline are unpaired. Unless stated otherwise, \(\pm\) denotes the sample standard deviation across independently seeded fits on the same partition, not a confidence interval or variation across data splits. Ensemble scores are ROC-AUCs of combined predictions and are reported separately from mean individual-model ROC-AUC.


Molecular Representations

Categorical graph features. Using OGB's nine categorical atom features and three categorical bond features. OGB AtomEncoder and BondEncoder modules sum learned embeddings of the individual categorical fields. Bonds are represented in both directions in the supplied graph. Bond embeddings are computed once per forward pass and reused across propagation layers in the GINE, PNA, and residual gated implementations. The GIN virtual-node model does not use bond features.


Additional atom attributes. The architecture cohort add three RDKit-derived values per atom: its contribution to topological polar surface area (TPSA), atomic mass, and a hydrogen-bond-donor indicator defined by RDKit's donor SMARTS matches. The values are divided by fixed scales \((40,200,1)\) and passed through a \(3\rightarrow d\rightarrow d\) MLP with an intermediate ReLU. Its output is added to the categorical atom embedding. These scales are fixed constants, not estimated from held-out data. The historical five-seed GINE, masking, and fusion runs do not include these attributes; this was verified from checkpoint tensors, which take precedence over subsequently edited configuration files.


Fingerprint features. The Morgan representation is a 2,048-bit radius-2 fingerprint. The rich representation concatenates four RDKit bit vectors: radius-2 Morgan (2,048 bits), radius-2 feature Morgan using feature-based atom invariants (2,048 bits), MACCS keys (167 bits), and a hashed atom-pair fingerprint (2,048 bits), giving 6,311 bits. Fingerprints are not standardized. When normal SMILES sanitization fails, extraction retries with sanitization disabled, a non-strict property-cache update, and ring initialization. If fingerprint generation still fails, the implementation emits an all-zero vector and a warning. No molecule is removed. Atom-attribute extraction uses the same parsing fallback but raises an error if attributes cannot be calculated or atom counts disagree.
